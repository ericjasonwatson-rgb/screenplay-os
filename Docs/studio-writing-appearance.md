# Writing surface appearance

The script is the primary visual surface: a centered paper area within a charcoal work surface. White paper and dark ink are explicit colors, independent of macOS dark appearance. Both the legacy continuous editor and the minimal package editor offer a Dark Page switch; this is display state only and does not dirty the screenplay. Display text uses Courier with bold Courier for headings (system monospace fallback if unavailable). The legacy screen font is 14 points at 100% display zoom. Printed layout and file formats are unchanged by this pass.

The initial/reset writing layout keeps navigation and context panels closed. Mode and Workspace stay visible, and panels remain available through their existing controls. The surrounding shell uses slate/charcoal layers, restrained gradients and a low-contrast fine horizontal texture, with a paper border and subtle shadow. Ableton, Premiere and Lightroom informed the desktop-workstation direction; this is an initial visual treatment, not a reproduction of any one product or a completed redesign of every workspace.

Validation: 136 Swift tests, 37 Python tests and 14 self-tests passed (187 checks). Writing startup assertions now reflect the requested closed-panel default and white page. Release build passed. Native screenshots verified the centered white surface, dark-page alternative, persistent navigation bar, and Courier package text in both paper colors. Switching package paper color retained text, selection and the clean save state. Final UI was left on the white main writing surface with panels closed. No user screenplay text was edited during visual verification.
