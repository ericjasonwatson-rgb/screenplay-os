# Linear Edit Spine

Edit now places the whole story in a horizontal strip below the scene script and
viewer. The upper area and timeline are separated by a resizable divider. The old
right-hand vertical Story Spine list has been removed from the workbench.

Every editorial scene appears left to right in editorial order, even before
shots or boards exist. Selecting a scene uses the shared scene-selection command,
updating the script and viewer. Existing clips appear below their scene; selecting
a board clip uses the existing board-selection command. External scene changes
scroll the strip to that scene. Timeline zoom is independent of script-page zoom.

The scene strip is an order overview; its card widths do not claim a runtime.
A separate duration-proportional clip lane now provides a time ruler and global
playhead. The viewer transport plays boards/placeholders across the whole edit.
Right-click a scene to move it earlier or later without moving screenplay text.
Scenes without clips remain visible but have no invented runtime.

Clip trimming, drag reordering, track editing, and video playback remain future
work. See [edit order and imports](edit-order-and-document-import.md) for the
legacy 1.2 persistence boundary and remaining source-link limitations.
