# Linear Edit Spine

Edit now places the whole story in a horizontal strip below the scene script and
viewer. The upper area and timeline are separated by a resizable divider. The old
right-hand vertical Story Spine list has been removed from the workbench.

Every editorial scene appears left to right in existing story order, even before
shots or boards exist. Selecting a scene uses the shared scene-selection command,
updating the script and viewer. Existing clips appear below their scene; selecting
a board clip uses the existing board-selection command. External scene changes
scroll the strip to that scene. Timeline zoom is independent of script-page zoom.

This is a scene-order overview, not a duration-proportional whole-film timeline.
Scenes without clips say “No timed clips”; their widths do not claim a runtime.
The viewer transport still plays the selected scene's boards. Whole-film playback,
clip trimming, drag reordering, track editing, media playback, and a global time
ruler remain future work. No document format or editorial ordering is changed.
