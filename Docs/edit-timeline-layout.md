# Edit workspace layout

The October 4, 2026 layout follows the viewer-above/timeline-below arrangement familiar from desktop NLEs. Scene Script is optional, initially hidden. The previous large fixed-width scene cards have been removed so there is only one visual timeline.

The lane uses the existing derived Edit timeline; scene estimates and authored clip durations remain unchanged. Widths are proportional to duration. Fit shows the complete film, while zoom expands it up to 32 times. The ruler uses 24 fps timecode labels; dragging it seeks the existing playhead. Clip selection, contextual scene reordering, playback, and NLE exports retain the same model. Untimed scenes remain available in a menu.

Muted blue estimated scenes and teal timed clips sit on a charcoal lane. Selected scenes have yellow outlines; the playhead is orange. This is a scene/board timing interface, not a claim of media decoding, audio tracks, trimming or a finished NLE. No waveform or footage thumbnail is fabricated.
