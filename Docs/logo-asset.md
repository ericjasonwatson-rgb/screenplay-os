# Initial ScreenplayOS logo

User-supplied artwork, adopted September 12, 2026.

Source: https://chatgpt.com/s/m_6aa5af5e6b648191bfa415d50aff4010

The original downloaded PNG is retained in Sources/ScreenplayOSApp/Resources/ScreenplayOSLogo.png. No cropping, redrawing, recoloring or text changes were made. The packaging script resizes it into standard macOS icon representations. Its white surround is part of the supplied artwork.

The logo appears as the app icon and as a small About ScreenplayOS button in the native toolbar. The About window displays the complete image at a readable size. Both the button and the application menu open the same window; neither alters or navigates the screenplay. The small toolbar image is an identity marker, not a readable wordmark.
