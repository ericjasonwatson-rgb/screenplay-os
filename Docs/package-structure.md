# Structural editing for minimal packages

The experimental Mac package editor can add, split, delete, and change types of paragraphs. This stays within the existing two-file minimal profile. Companion files, formatting runs, anchors, production locks, and unknown semantics still prevent editable opening; nothing is stripped to enable an edit.

Return splits the selected paragraph at the caret, replacing any selected text. The original UUID remains on the prefix; a fresh UUID identifies the suffix. Character and parenthetical paragraphs continue as dialogue; other supported types continue as action. Shift-Return (or Option-Return) inserts a line break inside the paragraph. Paste retains embedded line breaks. Native marked-text composition does not invoke a split. UTF-16 selection is checked against Swift grapheme boundaries before slicing Unicode text.

Add Paragraph inserts a blank action after the selected paragraph, or creates the first paragraph in an empty document. The type picker changes only the selected paragraph's type. Delete Paragraph removes that paragraph and selects its neighbor; deleting the last paragraph leaves a valid empty screenplay with Add Paragraph available. Empty paragraphs remain authored content.

Commands live in PackageTextSession, use stable UUID targets and expected session revisions, and validate candidate snapshots before committing. Structural edits preserve surviving element token bytes; array separator whitespace may change. Type/text changes replace only the relevant string token. Undo/Redo restores exact prior byte snapshots and the same paragraph UUIDs. Undo of a split selects its original paragraph; undo of deletion selects the restored paragraph. Pending text is applied before structural commands as a separate text transaction, so a second Undo can revert that pending-text application. Pending typing Undo retains the existing whole-draft behavior; fine-grained typing history remains future work.

The native text adapter delegates structural commands to this shared command layer. Save still writes a verified separate copy, and recovery stores the resulting supported package snapshot including paragraph order, IDs, types, and pending text. Recovery does not retain Undo history.

Automated coverage includes stable targets after array changes, stale/duplicate/unsupported requests, exact Undo/Redo, deleting all paragraphs and starting again, Unicode splitting and invalid boundaries, type transitions, restored selection, recovery, separate-copy save/reopen, and original preservation. The wider preservation and package suites also run.

Native verification, 2026-09-14: Return inserted an action after a scene heading and retained typing focus; Shift-Return inserted an embedded line break without creating another paragraph. The type picker changed it to Character; Delete, Command-Z, and Command-Shift-Z restored/deleted the same paragraph. Return from Character created Dialogue. Save Edited Copy and reopening preserved the four paragraphs, including an empty character paragraph and the new dialogue. Add Paragraph and Undo returned exactly to the saved state. The 740-point-wide sheet displayed all controls without clipping. Disk checks confirmed unchanged original elements and distinct new UUIDs. The full automated run passed 103 Swift tests, 37 Python tests, and 14 self-tests. IME composition is guarded in the native adapter but has not been exercised with a live input method.
