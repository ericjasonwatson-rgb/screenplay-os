# Package writing shortcuts and character suggestions

Within the continuous package text view, Tab cycles the current paragraph through Scene Heading, Action, Character, Dialogue, Parenthetical, Transition, General, and Shot; Shift-Tab reverses that order. The operation uses the existing stable-ID type command and preserves text and selection. A selection spanning paragraphs is left unchanged. Native marked-text composition retains control of these keys.

Typing a nonempty prefix at the end of a Character paragraph shows up to five matching character cues from this screenplay, in document order. Matching and deduplication are case-insensitive; acceptance preserves the existing cue's spelling. Action/dialogue text is not a source of names. Names with embedded newlines are excluded. The fixed-height, horizontally scrollable suggestion area avoids moving the writing surface or overflowing with long names.

Down selects/cycles suggestions, Up moves back (or clears the first highlight), and Return accepts a highlighted name as one undoable text replacement. Without a highlighted name, Return retains normal paragraph creation. A name button also accepts it and restores the writing caret to the cue's end. Escape or Dismiss hides suggestions without changing the screenplay; the dismissed prefix stays hidden until the input context changes. Selection away from the cue's end hides suggestions. Tab always changes type rather than accepting a name.

Suggestions are derived local UI state. They do not create character records, rewrite other cues, call services, or change the package format. Acceptance uses existing text commands, separate-copy saving, and recovery. The minimal supported editing profile remains unchanged.

Automated native-text tests cover cycling and wraparound, stable identities, selection, cross-paragraph protection, prefix matching/deduplication, dismissal, explicit acceptance, Undo/Redo, ordinary Return, source-byte preservation, and save/reopen. The full suite passed 119 Swift tests, 37 Python tests, and 14 self-tests.
